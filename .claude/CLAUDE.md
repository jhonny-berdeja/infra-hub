# infra-hub

Este proyecto gestiona los manifiestos de Kubernetes de las apps del ecosistema jtagram.

Las convenciones de desarrollo de los workflows de GitHub Actions **no** viven acá: están en el proyecto padre `jtagram`, en `.claude/infra/`.

## Regla

Antes de desarrollar algo en este repo, asegurate de tener clonado el padre `jtagram` (como carpeta padre) para tener disponible esa guía de convenciones.
